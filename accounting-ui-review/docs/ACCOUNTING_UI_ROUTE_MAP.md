# ACCOUNTING_UI_ROUTE_MAP.md
Source inventory of Sarveda Native Accounting + Purchases admin UI routes.
Access model (all accounting routes unless noted):
- Feature flag: `NEXT_PUBLIC_ACCOUNTING_ENABLED=1|true` (frontend) + backend `NATIVE_ACCOUNTING_ENABLED` for data.
- Email allowlist: `isAccountingEmailAllowed(user.email)` via `frontend/lib/accounting-access.ts` (default: arjun@, partha@, accounts@, deepak@sarveda.com; override via `ACCOUNTING_ADMIN_EMAILS` / `NEXT_PUBLIC_ACCOUNTING_ADMIN_EMAILS`).
- Not gated by ADMIN vs SUPER_ADMIN role in these layouts; requires normal admin auth (`AdminAuthBoundary`).
- Purchases ops flag: `NEXT_PUBLIC_PURCHASES_ENABLED=1|true`.
- Sidebar: when accounting email+flag on → nested `AdminAccountingSidebarTree` under Ops; flat "Purchases" link only when accounting off and purchases on.
